You have a graph of n nodes. You are given an integer n and an array edge 
where edges[i] = [ai, bi] indicates that there is an edge between ai and bi in 
the graph.

Return the number of connected components in the graph using BFS.

Input Format:
-----------------------
Line1 contains ‘n’ number of nodes and ‘m’ number of edges, 
followed by value for m edges.

Sample Testcase:1
----------------------------------
input=7 4
0 1
1 2
3 4
5 6
output=3

Explanation:
----------------------
First component having nodes 0, 1, 2 and second component having 
nodes 3, 4 and 5,6


import java.util.*;
class Solution{
    
    int countConnectedComponents(Graph graph){
        int c=0;
        
        
        boolean[] visited=new boolean[graph.V];
        for(int i=0;i<graph.V;i++){
            if(!visited[i]){
                c++;
                Queue<Integer> q=new LinkedList<>();
                visited[i]=true;
                q.add(i);
                while(!q.isEmpty()){
                    int p=q.poll();
                    //System.out.print(p+" ");
                    for(int e:graph.adjList[p]){
                        if(!visited[e]){
                            q.add(e);
                            visited[e]=true;
                        }
                    }
                }
            }    
        }
        

return c;
        
    }

public class Solution {
    static void dfs(int start, ArrayList<ArrayList<Integer>> adj, int n) {
        Stack<Integer> s=new Stack<>();
        boolean[] visited=new boolean[n];
        s.add(start);
        visited[start]=true;
        while(!s.isEmpty()){
            int p=s.pop();
            System.out.print(p+" ");
            for(int i:adj.get(p)){

You are given an array of positive integers and an integer K.
Your task is to find the maximum length of a continuous subarray
(a sequence of consecutive elements) such that the sum of all elements
in that subarray is less than or equal to K.

In simple words —
find the longest stretch of numbers in the array whose total is not more than K.

-----------------------------------
input=9
3 1 2 7 4 2 1 1 5
13
output=5

import java.util.*;

public class LongestSubarrayWithSumK {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        int n = sc.nextInt();
        int[] arr = new int[n];
        for(int i = 0; i < n; i++){
            arr[i] = sc.nextInt();
        }
        int K = sc.nextInt();

        int left = 0, right = 0;
        int sum = 0, maxLen = 0;

        while(right < n) {
            sum += arr[right];

            // If sum exceeds K, shrink window from left
            while(sum > K) {
                sum -= arr[left];
                left++;
            }

            // Update max length of valid window
            maxLen = Math.max(maxLen, right - left + 1);

            right++;
        }

        System.out.println(maxLen);
        sc.close();
    }
}
